# Security Policy

## Supported version

Security fixes are applied to the current `main` branch.

## Reporting a vulnerability

Do not open a public issue containing exploit details, tokens, personal data or a working attack.

Use the repository's **Security** tab and select **Report a vulnerability**. Include:

- the affected file or workflow;
- impact and prerequisites;
- reproduction details;
- any suggested mitigation.

Credential leaks should also be revoked at their issuing service immediately.
