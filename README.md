## A living companion to Pywel

Crimson Desert is too large, interconnected and changeable for a loose pile of articles. This project treats the game as a living world that must be **mapped, verified, cross-referenced and maintained**.

The guide combines complete walkthroughs with a searchable database, interactive completion tools, build planning, world intelligence, technical diagnostics and automated patch surveillance. Every meaningful gameplay claim carries evidence and patch context, so confirmed information never quietly blends into guesswork.

## Evidence before folklore

Every guide page can be audited back to its source and the game state in which it was verified.

| Grade | Meaning |
|---|---|
| **`official`** | Directly supported by Pearl Abyss material |
| **`verified`** | Reproduced through controlled in-game testing |
| **`community`** | Independently corroborated by multiple credible reports |
| **`provisional`** | A useful lead that still requires confirmation |

## Engineering the guide

- **Astro 6 + Starlight** provide the static documentation platform.
- **Pagefind** supplies fast local full-text search.
- **Cloudflare Workers Builds** publish production and preview deployments.
- **GitHub Actions** validate content, test local state systems, scan security and monitor patches.
- **Local-first browser storage** protects completion, Atlas, notes, catalogue, build and research progress.
- **Root and `/crimsondesert/` subpath builds** remain protected for the planned TKB Gaming migration.

### Local development

Requires Node.js **22.12.0 or newer**.

```bash
npm install
npm run dev
```

Complete validation:

```bash
npm run check:all
```
