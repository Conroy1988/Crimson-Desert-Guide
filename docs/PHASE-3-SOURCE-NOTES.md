# Phase 3 Source Audit

Research checked on 25 July 2026 for the beginner-guide release.

## Current baseline

- Patch 1.14.00 is the latest official update listed by Pearl Abyss.
- All supported platform rollouts are listed as available.
- The official Known Issues notice was last updated 20 July 2026.

## Primary sources used

- Patch 1.14.00 and Cross Save Guide
- Save Data Notice
- Current Known Issues
- Frequently Asked Questions
- PC, Console and Mac Performance Specs
- Patches 1.00.03, 1.02.00, 1.03.00, 1.04.00, 1.04.02, 1.06.00 and 1.09.00

## First-party project source

Conroy's original Steam guide was used to preserve the project's existing beginner principles and route structure. Claims that could not be tied to an official source were retained only as editorial or community guidance rather than reclassified as official facts.

## Exclusions

- No exact boss route or story quest order was added.
- No universal graphics preset or exact frame-rate promise was added.
- No unverified best weapon or permanent build claim was added.
- No external article text was copied into the guide.
