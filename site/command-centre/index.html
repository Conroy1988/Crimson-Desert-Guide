Operating rules

Section titled “Operating rules”
  • Expedition objectives are private planning records, not proof that content has been completed or verified.
  • The guide-wide spoiler profile configures compatible filters but does not delete manually revealed records.
  • The complete guide vault contains only supported local guide keys and validates every included state shape before restoration.
  • Official imagery is selected through the provenance-controlled Pearl Abyss media registry; generic fantasy artwork is not used.
  • Clearing browser storage removes local Command Centre state unless a guide vault has been exported first.
