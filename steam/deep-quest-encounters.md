[h1]Deep Quest & Encounter Guidance[/h1]

The live website now contains a searchable Quest Walkthrough & Encounter Encyclopaedia covering 32 canonical records. This Steam section mirrors the safe operating rules; the website carries the filters, spoiler controls, private notes and preparation checklists.

[h2]Three evidence states[/h2]

[list]
[*][b]Supported guidance[/b] — the canonical record is verified and the published checkpoint is directly supported.
[*][b]Limited official detail[/b] — an official name, objective fact or blocker exists, but no full walkthrough is claimed.
[*][b]Research required[/b] — the identity is official while route, phases, weaknesses, statistics, rewards or replayability remain unresolved.
[/list]

[h2]Quest recovery order[/h2]

[olist]
[*]Confirm that the game is on the current guide patch.
[*]Check the required character and the exact objective state.
[*]Read the recorded blocker history before using an old workaround.
[*]Return to the title screen and reload the current save.
[*]Preserve the newest working save before restoring an older one.
[*]Record the exact failure state if the issue remains reproducible.
[/olist]

[h2]Verified Memory Fragment rematches[/h2]

After the first defeat, the official Memory Fragment records support rematches for:

[list]
[*]Muskan — Bonepit
[*]Corrupted Caliburn — Fort Musket
[*]Goyen — Spire of the Sun
[*]Draven, the Crowcaller — West Demeniss
[*]Clockwork White Horn — Gate to Advancement
[/list]

The guide does not currently claim exact phases, weaknesses, health values, damage values or reward tables for these encounters.

[h2]Named quests and Abysses[/h2]

Official patch records confirm names and selected progression facts for eleven quests and two Abysses. They do not provide enough evidence for complete objective-by-objective walkthroughs. The guide therefore records blockers and recovery guidance without inventing route, prerequisite or reward data.

[h2]Private preparation on the website[/h2]

The web encyclopaedia supports browser-only preparation checks and notes with validated JSON backup and restore. No account, cookies, telemetry or remote profile database is required for those features.
