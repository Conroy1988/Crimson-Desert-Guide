## Completion Companion

The website includes an interactive local-first tracker. Steam cannot run the same browser application inside a guide page, so this section provides the operating method and a compact starter checklist.

### Privacy and persistence

- No account, cookie, analytics service or remote database is required.
- Website progress is stored only in the current browser.
- JSON export creates a small backup containing stable milestone IDs and spoiler-reveal state.
- Imports are validated before replacing existing progress.
- Unknown IDs, unsupported schemas and files from another project are rejected.

### Deliberately incomplete categories

Boss/rematch and stronghold/liberation lists are not yet seeded. They will be added only after identities, prerequisites and completion conditions are verified. An empty category means **not yet mapped**, not that the game contains no relevant content.

### Patch handling

Completed stable IDs are retained when the tracker expands. Renamed IDs can migrate to their replacements, while retired IDs can be removed without corrupting the rest of the backup.
