[h2]Build archetypes[/h2]

The guide uses transparent test frameworks rather than tier lists:

[list]
[*]Field-Balanced — general reliability across routes and interruptions
[*]Defensive Control — safe reads, containment and recovery
[*]Aerial Mobility — terrain access and repositioning
[*]Ranged Pressure — distance, ammunition and reload control
[*]Heavy Impact — commitment-heavy pressure and crowd displacement
[*]Unarmed Chain — bare-hand chains, kicks and finishers
[*]Boss Reliability — repeatable defence, healing and punish windows
[*]Exploration Utility — traversal, interaction access and low interruption cost
[/list]

[h2]Controlled test method[/h2]

[list]
[*]Fix the save, character, equipment, target, arena and difficulty.
[*]Establish a repeatable baseline before changing one variable.
[*]Record failures, healing, resource pressure, recovery and terrain—not only successful attacks.
[*]Repeat the same trial before increasing confidence.
[*]Compare a character against their own baseline before attempting cross-character conclusions.
[*]Do not publish exact damage, DPS, stagger, frame, stamina or Spirit claims without recorded measurements.
[/list]

The website Build Laboratory stores private test sheets locally, scores seven personal observation dimensions and supports strict JSON backup/restore. Personal results are never promoted into canonical guide claims automatically.
