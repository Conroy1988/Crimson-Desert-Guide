## Current verified patch

**Version 1.15.00** was published by Pearl Abyss on **24 July 2026 at 02:40 UTC**.

The release is a focused stability and bug-fix update. It corrects several combat and equipment behaviours without introducing a new progression system or changing the guide's core opening route.

### Guide-relevant changes

- Fixed bosses appearing transparent during battle.
- Fixed equipped-gear lock state not being saved for Oongka and Damiane.
- Fixed an attack restriction while riding a quest-objective bear.
- Fixed Axiom Force crosshair behaviour outside its activation range.
- Fixed a camera zoom issue while swimming in certain locations.
- Fixed Wyvern summoning while airborne.
- Fixed Aerial Roll travelling too short a distance after Aerial Maneuver.
- Fixed Kliff's posture when using Blinding Flash Finisher on a slope.

The Mac App Store rollout was still listed as in progress when this guide baseline was verified. Other listed platforms had received the patch.

## Current known issues that affect guidance

The official known-issues notice currently includes two combat/input caveats relevant to this guide:

- With **Evasion Control** set to **Hold**, the original default Evasion key may still function after remapping.
- If Damiane dies immediately after using **Shield Toss**, her shield and related skills may become unavailable until the save is reloaded.

These are treated as defects, not intended combat rules.
