## Guide-impact protocol

When automation detects a higher patch version:

1. A GitHub issue is opened.
2. The patch is assessed against all guide categories.
3. Potentially affected pages move to `review-required`.
4. Official changes are recorded without copying the full patch notice.
5. Gameplay recommendations are retested before being marked current.
