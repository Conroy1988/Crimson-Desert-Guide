Use this page when the game is unstable, visually incorrect, ignoring inputs or placing save data at risk. It separates **current official defects** from **editorial diagnostic paths** so a workaround is never mistaken for a confirmed game fault.

:::danger[Do not delete save data to diagnose a technical fault]
Before changing drivers, resetting configuration, verifying files or reinstalling, create a manual save and preserve the newest known-good copy. Follow [Save, Storage & Inventory Safety](/start-here/save-storage/) for platform-specific backup and synchronisation precautions.
:::

## Operating method

1. **Preserve the state** — note the platform, patch, driver, location, action and settings involved.
2. **Match the symptom** — search the centre for the visible failure rather than guessing its cause.
3. **Apply the safe actions only** — change one variable and repeat the same test.
4. **Escalate deliberately** — open the warning section only after reversible tests fail.
5. **Report reproducibly** — include the exact conditions, not only “it crashed” or “it is blurry.”

## Supported technology baseline

Pearl Abyss officially lists FSR 3/4, DLSS 4/4.5 and Intel XeSS 3 support on PC, Upgraded PSSR on PlayStation 5 Pro, and FSR 3 on base PlayStation 5 and Xbox Series X|S. Frame Generation is officially supported on PC and Mac, not consoles. The PC version requires current DirectX 12. Performance figures in the official specification notice are internal-test results rather than guarantees for every system.

For normal image-quality setup, begin with [Essential Settings](/start-here/essential-settings/). Use this page only when tuning becomes diagnosis.

## Driver policy

The official FAQ recommends AMD driver **25.9.2 or later** and NVIDIA driver **581.29 or later** as a general baseline. A later driver is not automatically better when a current known issue names a regression. Record the existing version before updating or rolling back, and change drivers only after preserving saves and a reproducible test case.
